# Pitfalls — auditing: stamps and an Envers history

Reference for the `persistence-architect` skill, step 4c. What a model writes wrong without the
norm, each with the section of `@.claude/rules/persistence.md` that prevents it and one source.
**Observed** marks the ones reproduced while the exemplars were written and run against a real
Postgres (and MongoDB for the stamps), in a Spring Boot project from the Initializr (decision
`0149`, 2026-10-13); the rest come from the official documentation, re-read on that date.

Versions are never written here: resolve the project's own (`./mvnw dependency:tree`) before
applying a line that depends on one (`@CLAUDE.md` invariant 8).

## Writes the history does not see

| # | Pitfall | Norm | Source |
|---|---|---|---|
| 1 | A bulk JPQL `UPDATE`/`DELETE` (`@Modifying @Query`) on an audited entity changes the rows and leaves no revision, with no error. **Observed** | § Auditing · Relational; § Relational · Queries | Hibernate user guide, *Envers* — "bulk update and delete are not supported"; HHH-3554 (won't fix) |
| 2 | `CriteriaUpdate` / `CriteriaDelete` — the same gap through the Criteria API | § Auditing · Relational | Hibernate user guide, *Envers*; HHH-10318 |
| 3 | A change made outside the application — a script, another service, a manual `UPDATE` — has no revision: the history is the application's, not the database's | § Auditing · Relational | Hibernate user guide, *Envers* (listeners on the session) |
| 4 | The history rows are written at commit (`beforeTransactionCompletion`), not at flush: inside the writing transaction a query sees none, and a test that rolls back sees none. **Observed** | § Auditing · Relational | Envers' audit process; the integration test |

## Mapping

| # | Pitfall | Norm | Source |
|---|---|---|---|
| 5 | A `List` without an order column is a bag: a duplicate element is written **once** in `_aud` — two `"a"` tags in the live row, one in the history — with no error. **Observed** | § Auditing · Relational | Hibernate user guide, *Envers* — bags not supported |
| 6 | A child of the aggregate left without `@Audited`: the history of the root shows no change when only a child changed, or fails to read the relation | § Auditing · Relational | Hibernate user guide, *Envers* — relations to non-audited entities |
| 7 | A relation to a non-audited entity marked `targetAuditMode = NOT_AUDITED` reads the target's **current** state in a historic version, and a missing target is an `EntityNotFoundException` | § Auditing · Relational | Hibernate user guide, *Envers* |
| 8 | A personal-data field audited by default: the history copies it into every version, beyond the live row's own retention | § Auditing · Relational; `personal-data.md` § At rest | Hibernate user guide, *Envers* — `@NotAudited` |
| 9 | `@Version` expected in `_aud`: Envers leaves the optimistic-lock field out by default (`do_not_audit_optimistic_locking_field`). **Observed** in the schema export | § Auditing · Relational | Hibernate user guide, *Envers* — configuration |
| 10 | A `mappedBy` child list with `@OrderColumn` expected to need a join audit table: the order column goes in the child's `_aud` instead. **Observed** in the schema export | § Auditing · Relational | Hibernate's schema export |

## Schema

| # | Pitfall | Norm | Source |
|---|---|---|---|
| 11 | The `_aud` and revision tables left to schema generation: `ddl-auto: validate` refuses to start, or `update` creates them in production with nobody reviewing | § Auditing · Relational; § Migrations | Hibernate user guide, *Envers* — "generated by hbm2ddl" |
| 12 | A `NOT NULL` on a non-key `_aud` column copied from the live table: validation passes, and the first delete fails — `null value in column "status" of relation "orders_aud"`. **Observed** | § Auditing · Relational | The delete revision keeps the id only (`store_data_at_delete=false`) |
| 13 | A revision sequence whose increment differs from the mapping's `allocationSize`: the startup fails ("The increment size of the [revinfo_seq] sequence is set to [50] in the entity mapping but the mapped database sequence increment size is [1]"). **Observed** | § Auditing · Relational | Hibernate identifier generation |
| 14 | A missing `revend` column under the validity strategy: the startup fails ("missing column [revend] in table [orders_aud]") — the net works, the migration is wrong. **Observed** | § Auditing · Relational | Hibernate schema validation |
| 15 | No index on `revend` / `revend_tstmp`: the validity strategy updates the previous row by `revend` on every write, and the prune reads by `revend_tstmp` — Hibernate creates neither | § Auditing · Relational | Hibernate user guide, *Envers* — validity strategy; the schema export |

## The revision

| # | Pitfall | Norm | Source |
|---|---|---|---|
| 16 | An `int` revision number overflows into an `AuditException` that rolls the business write back | § Auditing · Relational | Hibernate user guide, *Envers* — revision entity |
| 17 | `@RevisionTimestamp` on an `Instant` with the validity strategy storing the revision-end timestamp: every update's commit fails — "class java.time.Instant cannot be cast to class java.lang.Long". **Observed** | § Auditing · Relational | The integration test; a `long` timestamp passes |

## The actor

| # | Pitfall | Norm | Source |
|---|---|---|---|
| 20 | `AuditorAware` returning `Optional.empty()` for an unauthenticated thread (the reference example does): every job and consumer writes `null` as the actor | § Auditing · Common | Spring Data Commons, *Auditing* — `AuditorAware` |
| 21 | A fallback actor (`"system"`) for a missing authentication: a lost security context — an `@Async` hop, a public endpoint the chain does not cover — is recorded as the system, and nobody learns which job wrote | § Auditing · Common | — (decision `0149`) |
| 22 | `AuditorAware<T>` whose `T` differs from the `@CreatedBy` field's type: the stamp is not set | § Auditing · Common | Spring Data Commons, *Auditing* |
| 23 | A project without a Spring Security filter chain: an HTTP request carries no authentication at all, so the strict resolver fails every audited write reached by HTTP. **Observed**, with `spring-security-core` alone — which leaves every endpoint open, unlike the starter | § Auditing · Common | The integration test |

## Configuration and reads

| # | Pitfall | Norm | Source |
|---|---|---|---|
| 24 | `@EnableJpaAuditing` on the `@SpringBootApplication` class: every slice without JPA fails — "JPA metamodel must not be empty". **Observed** on `@WebMvcTest` | § Auditing · Common | Spring Boot, *Testing* — user configuration and slicing |
| 25 | The default audit strategy, then an age-based prune by the revision's own timestamp: it deletes the version still in force. **Observed** — the red run of the prune test | § Auditing · Relational | Hibernate user guide, *Envers* — validity strategy and partitioning |
| 26 | Switching the audit strategy after rows exist: the old rows have no revision end, and the validity queries skip them | § Auditing · Relational | Hibernate user guide, *Envers* — validity strategy |
| 27 | A history query on the default strategy grows with the history: a correlated subquery per row | § Auditing · Relational | Hibernate user guide, *Envers* — "audit queries can be much slower" |
| 28 | `@EnableEnversRepositories` over a package narrower than the persistence adapter: Spring Boot's own JPA repository scanning backs off once it is declared, and a repository outside that package is never created — "No qualifying bean of type '…OrderSpringDataRepository'". **Observed**. Its base package is the whole persistence adapter | § Auditing · Relational | Spring Data JPA, *Envers* — configuration; the integration test |
| 29 | The history read through `RevisionRepository` and handed out as the persistence entity or the rehydrated aggregate: an old version may break an invariant the current code holds | § Auditing · Relational; § Boundary | — (decision `0149`) |

| 31 | The outbox, the idempotency keys or a scheduling table audited: a revision per relay pass and per prune, and a history of rows that exist to be deleted | § Auditing · Common | — |
